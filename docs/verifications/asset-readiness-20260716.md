# 美术资产 Readiness 审计

日期：2026-07-16

## 结论

欧洲主题的世界地图、17 个章节场景，以及 `art-v2` 的头像、Boss、装备、GUI 图标和地图状态节点均已接入应用。运行时通过一个坐标合同和 SVG 精灵视口直接裁切图集，不复制切片文件；欧洲主题作为当前默认外观，中式同构图集纳入自动化检查但尚未开放换肤入口。

## 自动化合同

- `chapterEnvironmentAsset()` 只接受 1-17 的整数章节号，非法输入抛出 `RangeError`。
- 世界地图和每章场景路径固定在 `/assets/environments/european/scenes/`。
- 测试读取 PNG 文件头，验证所有实际使用场景均为 640×360。
- `portraitSpriteAsset()`、`itemSpriteAsset()`、`bossSpriteAsset()`、`guiSpriteAsset()` 和节点/槽位解析器锁定领域 ID、网格坐标与规范路径。
- 自动读取两套主题的 PNG 文件头，验证 10 个运行时图集均存在、尺寸相同、为 8-bit RGBA，并确保欧洲/中式主题只替换路径、不改变格位。
- 浏览器验收覆盖 1440×900、1024×768 和 390×844；10 个头像、17 个地图节点、13 个商店商品与 Boss 场景均无错误裁切、损坏图片或横向溢出。

## 上线前剩余风险

- 环境 README 将资源描述为项目资产，但还应补充逐批次的生成来源或权利记录。
- `art-v2` GUI 面板仍需统一双主题画布尺寸并定义九宫格/组件坐标后，才能替换当前 CSS 面板。
- 中式主题虽然具备同构角色、Boss、装备和 GUI 图集，但启用前仍需主题状态、持久化和环境场景切换合同。
- 音频必须默认尊重用户选择，不应在学习页面自动播放。
