## 自动化合同

- `chapterEnvironmentAsset()` 只接受 1-17 的整数章节号，非法输入抛出 `RangeError`。
- 世界地图和每章场景路径固定在 `/assets/environments/european/scenes/`。
- 测试读取 PNG 文件头，验证世界地图、17 个章节、终局战场和胜利营地均为 640×360。
- `portraitSpriteAsset()`、`itemSpriteAsset()`、`bossSpriteAsset()`、`guiSpriteAsset()` 和节点/槽位解析器锁定领域 ID、网格坐标与规范路径。
- 自动读取两套主题的 PNG 文件头，验证 10 个运行时图集均存在、尺寸相同、为 8-bit RGBA，并确保欧洲/中式主题只替换路径、不改变格位。
- 自动读取资产清单，验证两套主题共 24 个预定成品图集均已提交、尺寸匹配且为 8-bit RGBA；母图与重复副本不进入运行时提交。
- 自动读取环境清单，验证欧洲/中式两套主题各有 20 张已提交的 640×360 场景。
- 自动读取两套主题的 24 个 SFX，验证稳定 cue 路径和 OGG 容器；原生 `Audio` 测试验证静音抑制与音量传递。
- 本地存档合同当前为 v4，继续严格验证 `sfxVolume` 的 0-1 边界、减少动效、背包和成就字段，并增加章节检查点进度；合法 v1-v3 存档自动迁移。
- 浏览器验收覆盖 1440×900、1024×768 和 390×844；10 个头像、17 个地图节点、15 件装备、提示药水与 Boss 场景均无错误裁切、损坏图片或横向溢出。
- 音频浏览器验收确认旧存档迁移、静音/滑杆联动、25% 音量持久化、移动端布局，以及 `ui-confirm.ogg`、`dialog-open.ogg` 的真实资源请求；控制台无警告或错误。

## 上线前剩余风险

- 环境 README 将资源描述为项目资产，但还应补充逐批次的生成来源或权利记录。
- `art-v2` GUI 面板仍需统一双主题画布尺寸并定义九宫格/组件坐标后，才能替换当前 CSS 面板。
- 中式主题虽然具备同构角色、Boss、装备和 GUI 图集，但启用前仍需主题状态、持久化和环境场景切换合同。
- BGM 保持未播放；后续启用前需增加独立音乐音量、路由切换和浏览器用户手势合同，不能在学习页面自动起播。
