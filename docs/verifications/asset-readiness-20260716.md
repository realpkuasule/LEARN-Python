# 美术资产 Readiness 审计

日期：2026-07-16

## 结论

本轮只把欧洲主题的世界地图和 17 个章节场景接入应用。它们同时满足当前 GUI 合同要求的稳定路径、640×360 固定尺寸、完整文件和可接受视觉质量。

## 分类结果

| 资产类别 | Readiness | 证据与处理 |
| --- | --- | --- |
| Fusion Pixel 简体中文字体 | Ready，已使用 | WOFF2 已自托管，包含 SIL OFL 1.1 许可文件。 |
| 欧洲章节环境 | Ready，已接入 | 17 章和世界地图均为 640×360 PNG；新增自动化检查并用于首页、地图、任务卡和章节工作台。 |
| 欧洲终局战场与胜利营地 | Ready，暂未引用 | 文件和尺寸合格，但当前应用还没有独立终局战斗与通关页面。 |
| 中式章节环境 | 技术 Ready，暂不接入 | 20 个场景路径和尺寸完整；Phase 1 文档锁定欧洲主题，当前没有换肤状态合同。 |
| 音频 | 技术 Ready，暂不接入 | 两套主题各有 4 首 BGM 和 12 个 SFX，OGG 可解析且时长与 manifest 一致；启用前需要静音、音量和用户偏好合同。 |
| 旧版 `game-art` 独立切片 | 不满足最终视觉标准 | 文件、Alpha 和旧 manifest 完整，但角色、Boss 与装备是低细节几何占位，不符合当前环境场景的质量基准。 |
| `art-v2` 角色、Boss、装备与 GUI | 视觉 Ready，交付格式未 Ready | 代表性视觉抽检通过，绝大多数双主题总图尺寸一致且 Alpha 有效；尚无 v2 运行时切片 manifest，GUI 总图在两个目录重复，欧洲/中式 GUI 面板尺寸分别为 1448×1086 和 1450×1085。 |
| `source`、`art-source` 与 `.DS_Store` | 非运行时资产 | 母图、备选图和系统文件不进入前端依赖，也不应随本次运行时代码提交。 |

## 自动化合同

- `chapterEnvironmentAsset()` 只接受 1-17 的整数章节号，非法输入抛出 `RangeError`。
- 世界地图和每章场景路径固定在 `/assets/environments/european/scenes/`。
- 测试读取 PNG 文件头，验证所有实际使用场景均为 640×360。

## 上线前剩余风险

- 环境 README 将资源描述为项目资产，但还应补充逐批次的生成来源或权利记录。
- `art-v2` 需要先去重、统一双主题画布尺寸，并生成稳定的组件坐标/切片 manifest，之后才能替换旧角色和 GUI 图标。
- 音频必须默认尊重用户选择，不应在学习页面自动播放。
