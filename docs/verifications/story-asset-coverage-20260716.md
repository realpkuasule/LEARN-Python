# 剧情视觉资产覆盖审计（2026-07-16）

## 审计结论

当前欧式与中式章节环境母版均已导入并切出 17 章及 3 个公共/终局场景；角色、Boss、魔法、装备、道具、VFX 和 GUI 的双主题透明母版也已导入 `public/assets/art-v2`，可作为统一质量基线。

双文化最终验收仍需把母版按旧组件契约切片并接入页面；当前不把母版数量直接等同于逐项剧情资产完成。

本报告审计的是资源生产覆盖。当前应用仍通过 `/assets/ui` 使用单套 GUI 路径，章节环境和 `game-art` 也尚未接入页面；资源完成后还需要单独实施主题状态、路径解析和界面切换控件，才能实现用户可见的一键换肤。

## 不需要生产的资产

以下内容不属于当前 PRD，避免为了“资源齐全”过度生产：

- 自由行走用完整瓦片地图与独立碰撞图层：PRD 明确使用 17 节点分区路线图。
- 宠物、坐骑、职业套装：MVP 没有宠物、坐骑或职业系统。
- 逐句口型、全动画过场、视频 CG：当前对话和通关演出由头像、场景、VFX 与 CSS 动画组成。
- 图片内文字版本：章节名、装备名、数值和错误信息由 HTML 提供，便于清晰显示、主题切换和无障碍访问。
