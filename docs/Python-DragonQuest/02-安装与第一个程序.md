## 核心讲解

### 在网站点亮第一行 Python

现在就使用页面右侧的「Python 代码（必填）」编辑器。删除原有内容后输入：

```python
print("Hello, Python!")
```

[实践检查点: first-run/success]
在右侧输入上面的代码并点击「运行练习」。冒险日志出现 `Hello, Python!` 后，才能继续下一段剧情。

代码会被发送到网站的隔离 Python 沙箱执行，不会要求你在电脑上预装 Python。检查点完成时，结果区会显示：

```text
Hello, Python!
```

**逐段解读**：

- `print` —— Python 内置的「喊话」指令，把内容显示在结果区。
- `()` —— 把要交给 `print` 的内容放在括号里。
- `"Hello, Python!"` —— 一段文字，也叫字符串；首尾引号必须成对。

整句翻译成人话就是：「Python，请把 `Hello, Python!` 显示出来。」

**这是冒险的第一个信号弹。只有一行，却意味着你已经让计算机准确执行了一条指令。**

### 改一改，观察输出

网站编辑器可以一次运行多行代码。试着把内容改成：

```python
print("勇者刘老三")
print("冒险开始！")
print(100)
```

点击运行后，Python 会从上到下依次执行，每个 `print()` 产生一行输出：

```text
勇者刘老三
冒险开始！
100
```

再试一次：

```python
print("勇者刘老三", "冒险开始！")
print("HP:", 100)
```

一个 `print()` 可以接收多项内容。用逗号隔开时，Python 会在它们之间自动留出空格。

> 这些尝试用于观察运行效果。准备正式通关时，把编辑器恢复为挑战要求的 `print("Hello, Python!")`。

### 故意写错一次——报错不是死咒

把右引号暂时删掉：

```python
# 故意错误示例：缺少右引号，请观察 SyntaxError
print("Hello, Python!)
```

[实践检查点: syntax-error/error]
把错误示例放进右侧编辑器并点击「运行练习」。冒险日志识别出 Python 报错后，才能查看会长的解释。

点击运行后，你会看到类似下面的错误：

```text
SyntaxError: unterminated string literal
```

这不是「你不适合编程」，而是 Python 在说：「这段文字只有开头，没有结尾。」

- `SyntaxError` —— 代码不符合 Python 的语法规则。
- `unterminated string literal` —— 字符串没有正确结束。
- 报错中显示的行号 —— 最值得先检查的位置。

把右引号补回去，再运行一次。以后看到错误时，先读错误类型和行号，再检查对应的代码。

[英雄: 刘老三]
「原来红色文字不是判我出局，而是在告诉我哪句咒语没写完。」

[友善NPC: 会长]
「没错。能读懂报错的勇者，比从不尝试的勇者走得更远。」

### 注释——写给冒险者看的笔记

注释写给人看，Python 执行时会跳过它。单行注释以 `#` 开头：

```python
# 这是勇者的第一句 Python 宣言
print("Hello, Python!")

print("HP:", 100)  # 这一段说明也不会被输出
```

**逐行解读**：

- 第一行整行以 `#` 开头，所以只是一条笔记。
- 第二行会执行并输出 `Hello, Python!`。
- 第四行的 `#` 写在代码后面；前面的代码照常执行，后面的说明被忽略。

注释常用于：

1. 解释为什么这样写，而不是逐字重复代码。
2. 标记待办，例如 `# TODO: 下一章加入勇者名字变量`。
3. 给队友或 AI 说明上下文和限制。

### 练习 2：制作角色登场牌（中等）

只用注释和 `print()` 制作一张三行角色登场牌：

```python

```

至少修改两处内容，并给其中一行添加行内注释。运行后确认注释没有出现在结果区。

### 练习 3：与 AI 一起扩展（综合）

请 AI 在不使用变量、条件、循环的前提下，把角色登场牌扩展到五行。把代码粘贴回网站编辑器，逐行检查：

- 是否只使用了 `print()` 和注释

- 实际输出是否与角色设定一致

如果 AI 使用了没学过的语法，请它重写，而不是不理解就直接接受。

## 可选扩展：搭建本地 Python 环境

> 本节适合想在课程网站以外继续编程的学员。可以现在做，也可以以后再做；跳过不会影响本章完成、奖励或后续章节解锁。

### 安装 Python

前往 [python.org](https://python.org) 下载当前受支持的 Python 3 版本。Windows 安装器通常提供「Add Python to PATH」选项，请勾选；macOS 安装后通常使用 `python3` 命令。

安装完成后打开终端：

```bash
python --version
```

如果系统找不到 `python`，在 macOS 或 Linux 上再试：

```bash
python3 --version
```

出现 Python 3 的版本号，说明本地环境可以使用。课程网站的执行环境与本机环境彼此独立：即使本机安装失败，网站练习仍然可以继续。

### 体验交互模式

在终端输入 `python` 或 `python3`。看到 `>>>` 后，可以逐行输入：

```pycon
>>> print("Hello, Python!")
Hello, Python!
```

输入 `exit()` 可以退出交互模式。

### 创建第一个 `.py` 文件

新建 `hello.py`，写入：

```python
# 我的第一个本地 Python 文件
print("Hello, Python!")
```

在文件所在目录运行：

```bash
python hello.py
```

macOS 或 Linux 也可能需要使用 `python3 hello.py`。本地输出与网站结果一致，就说明两条执行路径都已跑通。

如果安装或 PATH 配置遇到问题，可以告诉 AI 你的操作系统、安装来源、完整命令和完整报错；不要只发送一句「Python 不能用」。
