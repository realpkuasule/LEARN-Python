# Python 勇者斗恶龙 —— 分章教案

> 围绕一个文字 RPG 项目学习 Python。你会逐步实现角色、战斗、背包和存档等关键模块，并在终章综合挑战中把它们组装成可运行的游戏。学完 17 课，你收获的不只是一个游戏，更是「用编程思维看世界」的能力。

## 文档定位与权威顺序

为避免同一信息在多份文档中重复维护，发生差异时按以下顺序处理：

1. `PRD-Python-DragonQuest.md`：产品范围、游戏数值、Boss、装备和技术架构的唯一事实来源
2. `UI-UX-设计规范.md`：Web GUI 的视觉语言、布局、交互、组件状态与 UI 验收来源
3. 本 README：课程顺序、文档入口和通用教学约定
4. `01`—`17` 分章文件：每一课的正式发布内容
5. `讲Python-全知识点-勇者斗恶龙版.md`：早期总览稿，仅供快速浏览，不作为发布源

课程中的代码片段是独立教学示例，数值可以为讲解而简化；网站角色的持久化等级、经验、金币和装备以 PRD 为准。分章故事或示例里出现、但未列入 PRD 装备表的名称（如「传说之剑」）只算叙事道具，不自动成为产品装备。教程默认主角叫「刘老三」，实际产品中学员可以自定义角色名和头像。

## 每章结构

每一章都是可单独授课的完整教案，包含：

1. **冒险引入** —— 用 RPG 故事场景引出本章要解决的问题
2. **学习目标** —— 学完本章能做什么
3. **核心讲解** —— 概念 + 代码示例 + 逐行解读 + 类比
4. **AI 协作指南** —— 这个知识点在跟 AI 对话时怎么用
5. **实战练习** —— 3—5 个练习，最后一个为综合练习
6. **Boss 战（指定章节）** —— 以 3 组服务端隐藏测试、专属对话和奖励完成章节验收
7. **本章回顾** —— 一句话总结 + 下章预告

## 贯穿全书的角色

- **勇者刘老三**：教程默认主角，从「史莱姆克星」成长为击败恶龙的「赤帝之子」
- **魔法书（AI）**：你的冒险伙伴，能精准执行你的每一个指令——前提是你表达得足够清晰
- **冒险者公会**：学习编程的隐喻——登记、接任务、交任务

## 如何使用

- **自学**：按章节顺序阅读，所有必做练习都在网站右侧编辑器运行；本地安装、终端和文件操作会明确标为可选扩展
- **教学**：基础路径每章约 45—60 分钟；包含选读内容或 Boss 战的章节可拆成两次课
- **参考**：课程总览稿末尾提供概念 ↔ RPG 映射速查表；具体讲解以分章文件为准

## AI 协作的两种模式

- **辅导模式**：学员尚未通过当前练习时，可使用 3 级预写提示或基于 DeepSeek V4 Flash 的内置 AI 魔法书；导师只给提示和错误定位，不直接给完整答案
- **协作模式**：完成练习后，内置 AI 魔法书会切换到协作模式；也可以把章节 Prompt 复制到外部 AI 生成示例或扩展代码，但必须阅读、运行和验证结果
