# Python DragonQuest 视觉资产生产规范

## 1. 统一质量基准

`public/assets/environments/european/source/` 中的欧式章节环境母图是全项目最终质量基准。角色、Boss、魔法、装备、剧情道具和 GUI 必须达到同等级别，不再接受旧版的纯几何色块风格。

统一特征：

- 16-bit 高细节像素画；使用清晰、经过设计的像素簇，不使用平滑矢量轮廓伪装像素画。
- 3/4 俯视 RPG 视角；角色脚点、特效中心和场景交互区保持稳定。
- 至少包含主材质、中间色、阴影、受光边与少量高光；金属、石材、木材、布料和魔法能量能被直接区分。
- 轮廓在缩小后仍可辨识，内部细节在 1× 像素尺寸下不过度噪声化。
- 不使用现成游戏角色、Logo、字体或标志性道具，不在图片内生成可读文字。

## 2. 双文化皮肤约束

运行时皮肤 ID 固定为 `european` 和 `chinese`。两套资源必须共享组件 ID、输出尺寸、锚点、动画顺序和交互安全区，业务逻辑只切换资源根目录。

| 维度 | 欧式奇幻 | 中式奇幻 |
| --- | --- | --- |
| 建筑 | 石砌拱券、深色橡木、锻铁、黄铜 | 木构斗拱、月洞门、格栅、青石、青玉 |
| 家具 | 橡木、皮革、羊皮纸、烛台 | 漆木、竹简/素纸、铜器、灯笼 |
| 服装 | 罩袍、板甲、斗篷、皮甲 | 交领袍、札甲、披风、护臂 |
| 纹样 | 原创藤蔓、盾徽、几何符文 | 原创云纹、雷纹、回纹、山水边饰 |
| 乐器/法器 | 鲁特琴、法杖、魔导书 | 琴/阮、符板、玉简、法铃 |

中式风格通过结构、材质和服饰表达，不依赖图片内汉字；Python 与代码主题使用不可读的原创抽象符文。

## 3. 输出规格

| 类别 | 单组件尺寸 | 透明背景 | 动画/数量 |
| --- | ---: | :---: | --- |
| 章节环境 | 640×360 | 否 | 17 章 + 世界地图、终局战场、胜利营地 |
| 主角行走 | 128×128 | 是 | 4 方向 × 3 帧 |
| 角色头像 | 160×160 | 是 | 10 个可选头像 |
| 剧情 NPC / 普通怪物 | 160×160 | 是 | 8 个 NPC + 6 个普通怪物 |
| Boss | 288×288 | 是 | 10 个 |
| Python 魔法 | 128×128 | 是 | 8 种 × 4 帧 |
| 装备与消耗品 | 128×128 | 是 | 16 个 |
| 剧情道具 | 128×128 | 是 | 16 个 |
| 叙事/战斗 VFX | 128×128 | 是 | 12 个 |
| GUI 图标 | 72×72 / 96×96 | 是 | 状态图标、地图节点、装备槽 |
| GUI 面板 | 9-slice 或固定框 | 是 | 对话、状态、任务、Boss、按钮状态 |

透明资产的母图使用纯 `#FF00FF` 色键背景，去背后检查边缘去色、Alpha 通道和四角透明度。最终 PNG 只允许整数倍缩放并使用 `image-rendering: pixelated`。

## 6. GUI 套件

GUI 不只包含图标。每套文化皮肤需要同时提供：

- 对话框、角色状态框、任务卡、Boss 状态框、提示/错误框。
- 默认、悬停、按下、禁用四种按钮状态。
- 已完成、当前、锁定三种地图节点。
- 武器、头盔、铠甲、盾牌、饰品、鞋子六种槽位框。
- 金币、任务、龙、Python 符文、生命、魔力、经验、锁、提示药水图标。

文字、数值、进度条填充值和焦点状态继续由 HTML/CSS 提供，图片只承担可换肤的框体、角饰、纹理和图标，确保可访问性与清晰度。

## 7. 验收条件

只有同时满足以下条件才标记为已覆盖：

1. `european` 与 `chinese` 都存在同名组件。
2. 文件尺寸、锚点和动画帧顺序一致。
3. 透明资产具备有效 Alpha 通道，四角透明且无明显洋红溢色。
4. 在 1× 尺寸下轮廓清晰，在场景图上不显得像低分辨率占位符。
5. 清单可索引文件，且抽样渲染通过人工视觉检查。
