# 「勇者斗恶龙」游戏化编程教学网站 —— 需求文档

> 版本：v1.3 | 日期：2026-07-16 | 状态：核心需求与 UI/UX 基线已确认，开放决策见第八节

---

## 一、项目概述

### 1.1 一句话描述

一个让零基础学员在 RPG 冒险中学会 Python 编程的网页应用——在浏览器里写代码打怪物、升级、存档，17 章通关后收获一个真实可玩的文字 RPG 游戏。

### 1.2 核心价值主张

| 传统的编程课     | 这个网站                                             |
| ---------------- | ---------------------------------------------------- |
| 看视频被动学     | **动手写代码，即时反馈**                             |
| 学完不知道能干嘛 | **每章推进冒险进度，17章打完恶龙**                   |
| 没有成就感       | **HP条、经验值、装备、排行榜——游戏即学习**           |
| 遇到问题卡住     | **MVP 提供 AI 协作指南；Phase 3 上线内置 AI 魔法书** |
| 一个人学孤独     | **排行榜、公会系统，看见别人也在冒险**               |

### 1.3 目标用户

- **主要用户**：完全零基础的编程学习者（18-35岁）
- **使用场景**：独自在电脑前，每天 30-60 分钟，跟着课程边学边写代码
- **前置条件**：会用浏览器、打字、有自己的电脑（Windows/Mac）

### 2.3 RPG 游戏系统

#### 2.3.1 主地图

- 一张分区式冒险路线地图，17 个节点对应 17 章，不实现自由行走或独立地图引擎
- 从「冒险者公会」（第1章）出发，终点是「恶龙之巢」（第17章）
- 已通关的节点显示金色，当前节点轻微脉冲，未解锁节点为灰色并显示锁图标
- 点击节点先显示章节、目标、奖励与状态卡片，再由学员进入任务
- 节点之间有路径动画（通关后路径点亮）
- 同时提供等价文字列表，用于键盘导航、辅助技术与未来窄屏降级

#### 2.3.2 角色属性与成长

```

══════════════════════

MP  ███████░░░  85/120
EXP ██████░░░░  900/1600
══════════════════════
ATK 59  DEF 43

```

上图是第 10 章通关后、装备 FOR 循环长矛/缩进头盔/FALSE 之盾/WHILE 真言护符/布衣的示例面板；数值按本节升级与经济公式计算。金币计算为章节奖励 2750 + 前 5 场 Boss 奖励 1500 - 第 4 章购买 TRUE 之剑与 FALSE 之盾 200 = 4050；Boss 首件掉落不扣金币。课程代码块中的角色数据为独立教学示例，不直接改写网站角色存档。

- 初始基础属性：HP 100, MP 50, ATK 15, DEF 5, LV 1, 金币 0；角色面板显示值再叠加当前装备加成
- MVP 不设置职业系统；分章教案中出现的「战士/法师职业限制」属于错误处理教学扩展示例
- 完成章节 → 获得经验值 + 金币
- 经验值满 → 升级（HP上限+20, MP上限+10, ATK+3, DEF+2）
- 每章经验值：章节号 × 100（第1章100EXP，第17章1700EXP）
- 升级曲线：LV n 需要 n×200 EXP

#### 2.3.4 战斗系统

- 每章都有综合练习；其中 10 个指定章节把综合练习包装成「Boss 战」
- 普通章节完成综合练习即可通关；Boss 章节需击败 Boss 才能通关
- 击败 Boss → 章节通关 → 获得章节奖励，并额外获得 Boss 经验、金币和掉落物品
- Boss 列表（10 个）：
  - 第1-4章：无 Boss（学习基础知识）
  - 第5章 Boss：「条件判断」哥布林队长（条件判断挑战）（注：「条件判断」为名字，"哥布林"为种族；种族无实际意义，名字直接对应本章挑战，以下类推。）
  - 第6章 Boss：「缩进」岩石巨人（for 循环挑战）
  - 第7章 Boss：「循环」骷髅将军（while 循环挑战）
  - 第9章 Boss：「函数」暗影骑士（函数挑战）
  - 第10章 Boss：「背包魔王」（列表与元组挑战）
  - 第11章 Boss：「数据结构」火元素（数据结构挑战）
  - 第12章 Boss：「字符串妖精」（字符串处理挑战）
  - 第14章 Boss：「文件操作」古代守护者（文件操作挑战）
  - 第15章 Boss：「错误处理」地狱犬（错误处理挑战）
  - 第17章 Boss：「白帝之子」恶龙（综合挑战——完整文字RPG战斗）

- Boss 战测试规范：每个 Boss 战提供 3-5 组隐藏测试。题目必须声明测试契约：算法题优先采用「函数参数 → 返回值」，输入输出题采用「stdin → stdout」；必要时也可捕获指定输出。全部通过即击败 Boss。

- Boss 战流程：
  1. Boss 登场，同勇者进行交互式对话（无厘头吐槽，打破第四面墙，与本章知识点强关联）。勇者用上下键选择回复 → Enter 确认
  2. 对话结束，显示 Boss 属性面板和挑战题目
  3. 学员写代码 → 运行 → 系统用预定义的多组测试用例（输入→期望输出）验证
  4. 全部测试通过 → 击败 Boss → 播放胜利动画 → 获得奖励
  5. 第17章 Boss 战胜利后，播放特殊通关画面：「两千年前，刘邦斩白蛇，提三尺剑取天下。两千年后，刘老三斩白帝之子，用 17 章 Python 征服了代码世界。你祖宗用的是剑，你用的是 print()。时代变了。」

  **第12章「字符串妖精」**

  「♪~ 哎~♪~」吟游诗人酒馆里传来悠扬的歌声，一个由无数文字符号构成的妖精漂浮在空中：「欢迎来到字符串的世界，勇者！我是字符串妖精，这里的文字守护者。」

  「哈，乱码？那只是因为我还没被正确解码罢了。」字符串妖精身上的文字闪了一下，「很多人看到我就慌——全是 `�%&#@!` 之类的符号。但只要用正确的编码，我就是一个温柔的故事讲述者。」

  妖精突然凑近你：「说起来，我发现很多人对字符串处理一窍不通。分不清 `strip` 和 `replace`，不知道 `split` 怎么用，正则表达式看起像外星文。」

  「所以，我给你准备了一个挑战——三个字符串谜题。全部解开，我把这根字符串法杖送你。解不开——你就继续当个只会 `print("你好")` 的程序员吧。」

  「测试开始：我用字符串编织了三个谜题，每个都有测试用例。全部通过，字符串法杖归你。」

  **第14章「文件操作」古代守护者**

  古代守护者是一座由旧硬盘和乱码石碑组成的巨像：「файл не найден. ファイルが見つかりません. Fichier introuvable.」

  > [1] 你说什么？（错误答案。 -> 「你怎么这么懒？随便用个翻译软件翻译一下啊！」）
  > [2] ……文件不存在？（正确答案）

  「三千年了。三千年来每一个闯进来的人都问我同样的问题——『为什么文件打不开？』答案永远是——encoding 没写！」
  石碑上的乱码开始跳动：「你知道我见过多少人在 Windows 上用默认编码打开 UTF-8 文件吗？那些乱码的冤魂都去了哪里？他们变成了你现在看到的我。记住了，勇者——open() 的第三个参数永远应该是 encoding='utf-8'。」

  **第15章「错误处理」地狱犬**

  地狱犬三个头同时咆哮，然后互相撞到一起：「嗷——！抱歉，三个头不太好协调。」

  > [1] 你们要不要用 try-except 处理一下（正确答案）
  > [2] 三个头……那写代码的时候听谁的？（错误答案。-> 三个头一起喊道：「关你屁事！」）

  左头：「我是正常逻辑！」中头：「我是异常处理！」右头：「我是 finally——不管你们谁报错，我都得叫！」
  三头齐声：「问题是——我们从来没商量好谁是 try、谁是 except！所以每次有人扔代码过来，三个头同时执行，直接死锁。」
  中头盯着你：「你。你最好知道怎么用 raise 主动抛出异常。不然你会跟上一个勇者一样——写了 500 行代码，一个 try 都没有，然后被一个 FileNotFoundError 直接带走。不带存档的那种。」

  **第17章「白帝之子」恶龙**

  恶龙盘踞在金山上，金币噼里啪啦往下掉：「哦？又来一个。你知道前面那些 Boss 为什么都输了吗？」

  > [1] 因为他们不是最终 Boss
  > [2] 因为他们只考一章，你考全书

  发出低沉的笑声：「错。因为他们太认真了。一个教编程的游戏，骷髅在那纠结 break，骑士在那纠结 return——而我，根本不在乎代码规范。」
  站起来，翅膀遮住了整个屏幕：「我用全局变量。我的函数超过 200 行。我的字典和列表不区分的混着用。我不写注释。我的编码是 GB2312。我缩进用空格和 Tab 混着来。而且你知道吗——我的代码跑得通。没人知道为什么。连我自己都不知道。」
  低头，一只眼睛对准你：「你以为这是最后一关，考的是你学过的所有东西？不。这一关考的是——看到我这种代码，你有没有勇气说：『让我重构一下』。」

  恶龙突然停住，鼻子凑近屏幕：「等等。你叫什么名字？」

  「……刘老三？？？」

  恶龙后退三步，翅膀撞塌了一座金山：「姓刘的！！两千年前，你祖宗在芒砀山砍了一条白蛇。那条蛇是我太爷爷。」

  「从那以后，我们白帝蛇族改名叫 Python。你知道为什么吗？因为『白蛇』写在简历上不好看。『Python』听起来像跨国公司。」

  「所以——你是来学编程的，还是来算家族旧账的？」

  重新站定，低头：「算了。反正你祖宗用三尺剑斩蛇，你用 keyboard 写代码。来吧，刘老三。赢了，你就是『赤帝之子』。输了——欢迎来我的代码库做维护，我们家族等了 2200 年就为了找一个姓刘的免费劳动力。」

## 三、非功能需求

### 3.1 性能

- 首屏加载（LCP）< 2 秒
- 代码编辑器启动 < 1 秒
- 代码运行响应（沙箱执行）< 3 秒
- 支持 500 并发用户

### 3.2 安全

- 独立代码执行服务：使用 Docker 容器隔离，每次执行创建新容器，执行完销毁
- 代码执行限制：超时 10 秒、内存限制 256MB、禁止网络访问、禁止文件系统写入（除 /tmp）
- API 限流：同一用户每秒最多 3 次代码提交
- SQL 注入防护、XSS 防护、CSRF Token

### 3.3 兼容性

- 浏览器：Chrome 90+, Firefox 90+, Edge 90+, Safari 15+
- 屏幕：≥ 1024px 宽度（Phase 1 桌面优先，移动端适配推迟到 Phase 4）

### 3.4 可维护性

- 课程内容用 Markdown 文件管理（含 frontmatter 元数据和练习定义），支持热更新，具体 Markdown 模板格式在开发阶段定义
- 游戏数值（装备价格、经验曲线、HP 成长）通过配置文件管理，修改后 Git 提交即部署生效
